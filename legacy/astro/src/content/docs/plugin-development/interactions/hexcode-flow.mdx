## Full Interaction Tree

How a mouse click flows through hexcode's interaction system from item input to state machine.
All interactions are inlined into 8 root files — no standalone interaction JSONs.

```mermaid
flowchart TD
    subgraph Item["Hex Staff Item"]
        Primary["Primary (Left Click)"]
        Secondary["Secondary (Right Click)"]
    end

    subgraph PrimaryFlow["Primary Click — Hexcode_Staff_Primary"]
        PBranch["HexStateBranch"]

        MC["HexMode CASTING"]
        MD["HexMode DRAWING"]
        MK["HexMode CRAFTING"]
        ME["HexModeExit EXECUTION"]

        EC["HexModeExit CASTING"]
        ED["HexModeExit DRAWING"]
        EK["HexModeExit CRAFTING"]
    end

    subgraph SecondaryFlow["Secondary Click — Hexcode_Staff_Secondary"]
        SBranch["HexStateBranch"]

        subgraph CastingFlowDetail["Root_Hexcode_Secondary_CastingFlow"]
            direction LR
            CA1["EnterAnim\n0.2s"]
            CA2["HexStateChange\n→ CASTING"]
            CA3["HexHold\n(indefinite)"]
            CA4["HexStateChange\n→ IDLE"]
        end

        subgraph DrawingFlowDetail["Root_Hexcode_Secondary_DrawingFlow"]
            direction LR
            DA1["EnterAnim\n0.2s"]
            DA2["HexStateChange\n→ DRAWING"]
            DA3["HexHold\n(indefinite)"]
            DA4["HexStateChange\n→ CRAFTING"]
        end
    end

    Primary --> PBranch
    PBranch -->|"state = CASTING"| MC
    PBranch -->|"state = DRAWING"| MD
    PBranch -->|"state = CRAFTING"| MK
    PBranch -->|"state = EXECUTION"| ME

    MC -->|"release"| EC
    MD -->|"release"| ED
    MK -->|"release"| EK

    Secondary --> SBranch
    SBranch -->|"state = IDLE\nor EXECUTION"| CastingFlowDetail
    SBranch -->|"state = CRAFTING"| DrawingFlowDetail

    CA1 --> CA2 --> CA3 --> CA4
    DA1 --> DA2 --> DA3 --> DA4
```

## State Transitions

How the hex staff drives the state machine through interactions.

```mermaid
stateDiagram-v2
    [*] --> IDLE

    IDLE --> CASTING : Secondary Hold\n(CastingFlow → HexStateChange)
    CASTING --> IDLE : Secondary Release\n(CastingFlow → HexStateChange)

    IDLE --> CRAFTING : /hc draw crafting\n(command)
    CRAFTING --> IDLE : /hc draw crafting\n(command)

    CRAFTING --> DRAWING : Secondary Hold\n(DrawingFlow → HexStateChange)
    DRAWING --> CRAFTING : Secondary Release\n(DrawingFlow → HexStateChange)

    CASTING --> EXECUTION : Primary Click\n(HexModeExit EXECUTION)
    EXECUTION --> IDLE : Execution completes

    state CASTING {
        [*] --> Hovering
        Hovering --> Dragging : Primary Hold\n(HexMode CASTING)
        Dragging --> Hovering : Primary Release\n(HexModeExit CASTING)
    }

    state DRAWING {
        [*] --> Ready
        Ready --> Stroking : Primary Hold\n(HexMode DRAWING)
        Stroking --> Ready : Primary Release\n(HexModeExit DRAWING)
    }
```
