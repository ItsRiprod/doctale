This page summarizes the notable changes introduced in **Update 2** (the second server update). Since we do not have a complete v1-to-v2 diff, this is a high-level overview based on callouts found throughout the documentation.

## Commands

- The `/update` and `/git` command collections were added, providing server update management and version control utilities from within the game.

## Interactions

- `RunOnBlockTypes` interaction was added for AOE effects that target specific block types.

## World Generation

- `WeightedProp` and `OffsetProp` were added for more flexible prop placement during world generation.

## Server Systems

- The **Server Update System** was introduced, providing automated server update capabilities including download, staging, and application of server builds.
